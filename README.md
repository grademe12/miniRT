# miniRT

`.rt` 장면 파일을 읽어 구, 평면, 원기둥을 광선 추적으로 그리는 레이 트레이서입니다. 42서울 2인 과제로, 장면 파일 파싱은 팀원이, 렌더링은 제가 맡았습니다. (2024.06 – 2024.10)

포트폴리오 설명: <https://woosupar.dev/projects/minirt/>

| `scenes/temple.rt` | 구와 점광원 |
|---|---|
| ![원기둥과 구로 만든 신전 장면](https://woosupar.dev/images/minirt/temple.webp) | ![점광원에 비친 구와 그림자](https://woosupar.dev/images/minirt/sphere.webp) |

## 빌드와 실행

macOS의 MiniLibX(OpenGL, AppKit)에 맞춰 빌드합니다.

```bash
make
./miniRT scenes/temple.rt
```

`ESC`나 창 닫기 버튼으로 종료합니다.

## 장면 파일 형식

한 줄에 요소 하나씩 적습니다. 좌표와 방향은 `x,y,z`, 색은 `R,G,B`(0–255)입니다.

| 식별자 | 요소 | 값 |
|---|---|---|
| `A` | 주변광 | 밝기(0.0–1.0), 색 |
| `C` | 카메라 | 위치, 방향 벡터, FOV(0–180) |
| `L` | 점광원 | 위치, 밝기(0.0–1.0) |
| `sp` | 구 | 중심, 지름, 색 |
| `pl` | 평면 | 한 점, 법선 벡터, 색 |
| `cy` | 원기둥 | 중심, 축 벡터, 지름, 높이, 색 |

```
C	0,0,-200	0,0,1	70
A	0.1		255,255,255
L	-40,0,30	0.7

pl	0,-20,0		0,1.0,0		255,0,0
sp	20,40,30	30		0,255,0
sp	-20,40,-30	30		0,0,255
cy	0,0,0		0,1,0	10	10	0,0,255
```

(`scenes/subject.rt`)

`scenes/`에 예제 장면이 있습니다 (`temple`, `snowman`, `stickman`, `octagon` 등).

## 렌더링 흐름

1. 픽셀마다 카메라 위치, 방향, FOV로 광선을 만듭니다.
2. 장면의 모든 물체와 교차를 계산하고 가장 가까운 교차점을 고릅니다.
3. 교차점에서 광원 쪽으로 그림자 광선을 쏴서 가려지는지 판정합니다.
4. 주변광과 광원 각도로 밝기를 정해 MiniLibX 이미지 버퍼에 찍습니다.

## 오래 붙잡은 것

- **원기둥:** 옆면, 윗면, 아랫면의 교차를 따로 풀고, 그림자 판정도 면마다 나눴습니다.
- **그림자 거리:** 그림자 광선이 무언가에 닿아도 그 거리가 광원까지 거리보다 멀면 그림자가 아닙니다. 이 조건이 없어서 광원보다 아래에 있는 평면 전체가 그림자로 칠해졌습니다.
- **방향 벡터 정규화:** 입력받은 방향 벡터를 읽자마자 정규화하도록 바꿨습니다.
